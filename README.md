### 🧠 About `darkwiki`

> A private markdown-based documentation vault for everything hacking, OSINT, red teaming, and stealth tactics.  
> Think of it as a **blacksite for knowledge**, encrypted in plain sight — built for the hacker who documents like a spy.

---

### 📁 Wiki Modules

| Section | Description |
|--------|-------------|
| `docs/recon` | Reconnaissance techniques and tool notes |
| `docs/exploit` | Exploits, payloads, bypass strategies |
| `docs/stego` | Steganography theory, tools, CTF writeups |
| `docs/tools` | Quick references and tool cheat sheets |
| `docs/notes` | Personal notes, TTPs, and op logs |

---

### ⚙️ Features

- 📄 Clean markdown-based system
- 🌒 Dark mode optimized visuals
- 🧩 Highly modular — plug and document
- 🔐 Can be made private or public for select ops
- 🧠 Ideal for long-term hacker knowledge base
